# 女装视觉 × 销量影响算法 — 规范文档

> 场景：淘宝**统一风格类目**下，不同商家的主图与详情页设计（内容 + 质量）对销量的影响量化。
> 配套交互报表：`docs/ecommerce-visual-impact.html`
> 状态：v1.0 · 透明可解释框架 · 权重/基线可校准

---

## 1. 核心假设：销售漏斗归因

销量不是被"整体设计得好不好"决定的，而是被漏斗每一环的转化效率决定：

```
销量(单) = 曝光量 × 点击率 × 转化率
             ↑主图分决定  ↑详情页分决定
```

- **主图质量分** → 影响 **点击率（CTR）**
- **详情页质量分** → 影响 **转化率（CVR）**

> 简化假设：主图只影响点击、详情页只影响转化。真实世界二者有交叉（主图也塑造购买预期），v2 可加入交叉项。

---

## 2. 评分子模型

对每一环，用**加权线性合成**得到 0–100 分：

```
主图分     = Σ(主图维度_i × 权重_i)
详情页分   = Σ(详情页维度_j × 权重_j)
```

### 主图 6 维（合计 1.00）

| # | 维度 | 权重 | 考察点 |
|---|------|------|--------|
| 1 | 首图清晰度与光影 | 0.16 | 像素、打光、背景干净度 |
| 2 | 模特与穿着展示 | 0.20 | 姿态、版型、多角度 |
| 3 | 场景与氛围 | 0.12 | 贴合风格的场景情绪 |
| 4 | 卖点信息传达 | 0.20 | 核心卖点一眼看清 |
| 5 | 营销元素与价格 | 0.14 | 价格/活动标签，不过度 |
| 6 | **风格一致度** | 0.18 | 统一风格类目特有：视觉统一性、心智一致性 |

### 详情页 6 维（合计 1.00）

| # | 维度 | 权重 | 考察点 |
|---|------|------|--------|
| 7 | 首屏承接效率 | 0.20 | 面料/尺码/卖点 3 秒可见 |

## 3. 分数 → 转化率弹性映射（S 型）

每个维度分数合成后，用 **logistic 弹性曲线**把分数映射为对 CTR/CVR 的放大倍数：

```
放大倍数 U(s) = 1 + α · (σ((s − s₀)/k) − 0.5) / 0.5
σ(x)          = 1 / (1 + e⁻ˣ)
```

- `s` = 质量分（0–100）；`s₀` = 基准分（默认 60）；`k` = 曲线陡度（默认 15）
- `α` = 该环的最大放大潜力：主图 α=1.0（好主图可让点击率近翻倍），详情页 α=0.7
- 在 `s = s₀` 时 U = 1（不增不减）；`s → 100` 时 U → 1+α；`s → 0` 时 U → 1−α（接近 0）

```
CTR(s) = CTR_base · U(s)        CVR(s) = CVR_base · U(s)
```

### 默认基线（可取自已公开的类目经验区间）

| 参数 | 默认值 | 含义 |
|------|--------|------|
| 曝光量 | 100,000 / 月 | 平台分配，非视觉可控 |
| CTR_base | 4.0% | 类目点击率基准 |
| CVR_base | 2.2% | 类目转化率基准 |
| 客单价 | ¥189 | 用于 GMV 换算 |
| s₀ / k | 60 / 15 | 弹性曲线形状 |
| α 主图 / α 详情 | 1.0 / 0.7 | 最大放大潜力 |

### 销量与影响

```
销量 = 曝光 × CTR(s_主图) × CVR(s_详情)
较基准销量变化 % = U(主图分) · U(详情页分) − 1
```

## 4. 优化优先级（改哪格最划算）

对维度 `i`，**边际收益** = 该维度提升 +10 分带来的预计销量增幅：

```
Marginal(i) = [ 销量(vals | vᵢ+=10) − 销量(vals) ] / 销量(vals) × 100%
```

该值由三个因素共同决定，且自动反映"边际递减"：
1. 该维度**权重**（wᵢ）
2. 当前分数在曲线上的**斜率**（60–85 分区间最陡）
3. 另一环的**转化基数**（详情页分高时，改主图收益被放大，反之亦然）

排序后即得到"本周改图清单"——分数已接近 100 的维度会自然靠后（曲线饱和）。

## 5. A/B 对比

同一模型跑两家店铺，输出：

- 十二维雷达对比（主图 6 + 详情页 6）
- 同曝光下的漏斗对比（曝光 → 点击 → 转化）
- 销量差距归因：`差距主要来自点击还是转化？` → 决定先改哪家、改哪环

```
dClick = ΔCTR / CTR_B      dConv = ΔCVR / CVR_B
若 dClick > dConv → 差距主要来自主图（点击环）→ 优先改该店主图
否则             → 差距主要来自详情页（转化环）→ 优先改该店详情页
```

## 6. 校准指南（接入真实数据）

| 目标 | 方法 |
|------|------|
| CTR_base / CVR_base | 类目或店铺近 90 天均值（生意参谋 → 商品分析） |
| 各维度权重 | 线性回归 / 主成分分析：以历史销量为因变量，维度评分（可由运营或视觉模型标注）为自变量反推 |
| α（弹性幅度） | 用真实 A/B 测试结果拟合：记录某维度改版前后的 CTR/CVR 变化，反解 α |
| 维度评分来源 | 人工专家打分，或接入图像模型（清晰度、人脸姿态、背景杂度、文字区域占比等可自动化） |

---

## 7. 局限与边界

- **非黑箱预测器**：本模型用于**归因与优先级排序**，输出是相对量级而非精确承诺。
- **混淆变量未纳入**：价格、评价数、销量基数、流量结构、季节、退款率等现实中共同作用。
- **线性加权的局限**：极端差的单项（如首图糊掉）不是"加权拉平"能代表的，建议对单项设最低门槛（v1 未做，v2 可加惩罚项）。
- **静态假设**：α、k 默认值基于经验区间，接入真实数据后必须重新校准。
