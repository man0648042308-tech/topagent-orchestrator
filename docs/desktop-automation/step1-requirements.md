## 3. 产品定义

### 3.1 一句话定位
一个 **Claude 视觉驱动的 Windows 桌面自动化 CLI 工具**：连续截取指定应用窗口画面 → 交给视觉大模型识别要点击的元素 → 计算屏幕坐标 → 驱动鼠标完成点击，循环直至任务结束。

### 3.2 核心能力（MVP 范围）
1. **窗口锁定**：定位/锁定目标应用窗口，只在该窗口内操作
2. **屏幕采集**：定时/事件触发截取目标区域画面（`mss`/Pillow）
3. **视觉识别**：截图 + 任务指令 → `router/` 视觉模型 → 结构化输出目标元素描述/坐标
4. **坐标映射**：模型相对坐标 → 真实屏幕坐标（含 DPI/多屏缩放处理）
5. **鼠标执行**：`pyautogui` 移动+点击，含点击前后校验
6. **任务循环**：直到达到目标状态或任务指令完成
7. **急停机制**：全局热键 ESC 立即中止并释放鼠标
8. **日志审计**：每一步（截图/识别/点击/校验）记录，可回放

### 3.3 非目标（Phase 1 不做）
- ❌ 不处理任意通用桌面（本版本聚焦指定应用）
- ❌ 不做多模态复杂推理（只识别可点击元素，不做意图规划推理链）
- ❌ 不做GUI界面（CLI 满足）
- ❌ 不做训练数据管道（Phase 4 知识体系）

## 5. 明确的风险与边界（Step 2 将展开）

| 风险 | 说明 | 初步缓解 |
|------|------|---------|
| ⚠️ 误点风险 | 全自主模式模型判断错误会点击错元素 | 坐标校验 + 点击后状态快照对比 + 任务级成功率评估 |
| ⚠️ 模型幻觉坐标 | 视觉模型可能给出错误/越界坐标 | 坐标合理性校验（窗口边界内）、NMS过滤 |
| ⚠️ 不可逆操作 | 点击可能触发删除/提交等 | 白名单黑名单元素关键词（首版基础版） |
| ⚠️ DPI/多屏 | 缩放导致坐标偏移 | 使用物理像素坐标 + 窗口句柄定位 |
| ⚠️ 循环失控 | 任务未完成陷入死循环 | 最大步数上限 + 无进展检测 + ESC 急停 |
